# ⏰ Digital Clock & Stopwatch

A simple and interactive **Digital Clock and Stopwatch Web Application** built using HTML, CSS, and JavaScript. This project was developed as part of my Web Technology practice to strengthen my understanding of JavaScript, DOM manipulation, event handling, and time-based operations.

## 🌐 Live Demo

**[View Live Application](https://digitalclockwebtechpractice.vercel.app/)**

## ✨ Features

### 🕒 Digital Clock
- Displays the current local time in real time.
- Automatically updates every second.
- Supports both **12-hour and 24-hour** time formats.
- Allows users to switch between time formats using dedicated buttons.
- Dynamically displays the current date, including the weekday, month, and year.

### ⏱️ Stopwatch
- Start the stopwatch to begin tracking elapsed time.
- Pause the stopwatch without losing the recorded time.
- Reset the stopwatch back to zero.
- Displays elapsed time in hours, minutes, and seconds.
- Prevents multiple stopwatch intervals from running simultaneously.
- Provides status messages indicating whether the stopwatch is ready, running, or paused.

### 🎨 User Interface
- Clean and modern interface.
- Responsive layout using CSS.
- Separate sections for the digital clock and stopwatch.
- Interactive buttons with visual styling.

## ⚙️ Key JavaScript Concepts Practiced

This project demonstrates several fundamental JavaScript concepts:

- **Date Object:** Retrieving the current date and time.
- **Intl.DateTimeFormat:** Formatting time and date according to the selected format and browser locale.
- **setInterval():** Updating the digital clock and stopwatch at regular intervals.
- **clearInterval():** Pausing and resetting the stopwatch.
- **DOM Manipulation:** Dynamically updating displayed time, date, and stopwatch status.
- **Event Listeners:** Handling user interactions with buttons.
- **Conditional Logic:** Managing stopwatch states and time format selection.
- **Time Calculations:** Calculating elapsed time using `Date.now()`.
